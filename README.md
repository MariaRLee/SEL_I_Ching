# SEL 易想天開｜SEL I Ching: Open Possibilities

**An Interactive Reflection and Social-Emotional Learning Game · V1.0.7**

## 本版內容

本版依照教師版指引學習單製作，完整流程為：

1. 選擇個人或小組模式。
2. 填寫問題及卜卦前共同討論的解方。
3. 組員輪流擲骰六次；單數為陽爻、偶數為陰爻，並由下往上形成六爻。
4. 系統自動找出本卦及上下倒轉後的綜卦。
5. 每位成員分別填寫自己的解釋、感受及需要。
6. 小組共同詮釋本卦、綜卦，並形成一項具體下一步。
7. 產生「AI 反思摘要」。V1.0.7 採本機規則整理，不連接外部 AI。

## GitHub Pages 部署

1. 建立新的 Public repository，例如 `SEL-Yixiangtiankai`。
2. 將 `index.html`、`terms.html`、`README.md` 上傳到 repository 根目錄。
3. 開啟 **Settings → Pages**。
4. Source 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按 **Save**。
6. 等待數分鐘後，以 GitHub Pages 網址開啟遊戲。
